# fpaniagua-utils

Módulos de utilidad.

## Módulos

- `data_generator_file.py`: Genera un fichero CSV con datos de empleados ficticios. Solicita número de registros, nombre de fichero y rango de salario.
- `data_generator_db.py`: Crea una base de datos SQLite y rellena una tabla `empleados` con registros aleatorios. Solicita número de registros, nombre de base de datos y rango de salario.
